## 一、核心需求

**替代 ElevenLabs（https://elevenlabs.io/zh），省钱。**
员工现在付费用 EL 生成韩语财经配音。唯一验收标准：
> 同一条韩语文案，我们生成的 vs EL 生成的，员工听不出差别。

### 名词指代（写错就会全盘跑偏）
- **EL = ElevenLabs**。案例库 36 条**全部是 EL 生成的**，不是真人录音。
  员工从 EL 上找到或重新生成的语音+文案，上传到我们平台做对比拆解。
- `EL_male` / `EL_female` = 从 EL 产出里提取的 15s 标杆参考音频。
- ⭐ **"音色来源"和"质量标杆"是同一个东西**——都是那条 EL 语音。
  它既是克隆的参考音频，也是打分的对比基准。别拆开去找别的音色来源。
- 案例库实测只有 2 个核心声音（campplus 嵌入聚类，阈值 0.75）：
  SOLA 女 22 条 / yohan 男 13 条 / elara 1 条。旧的"4 个人"说法作废。
- 员工只有两步：**上传文案 + 选男/女 → 生成**，零调参。
  情绪下拉框已于 10-12 下架：情绪是**复刻案例自带的**，不是让员工选。

## 二、验收铁律

**音色、语调/韵律、内容完整性必须同表看，只看音色会选错引擎。**
铁证：GS 微调女声音色 0.943 全场最高，同一次推理覆盖率只有 0.150、CER 0.808。

- 判定线：覆盖率 <0.85 = 吞字；冗余率 >0.30 = 重复念；音色 <0.90 = 偏低。
- 工具：`tools/engine_score_all.py`（音色 + 语调 10 维 + 完整性一次跑完）。
- 参照必须是**案例未训练区原声**，否则开卷考试。
  ⚠️ `EL_male`/`EL_female` 的 15s 参考**正是**取自案例 `1a6c20a60481` /
  `00b6a45ad6aa` → 拿这两条验收是**开卷**，只能当上限看。
- 男声那批案例的**参照自身** CER 就有 0.096~0.102（ASR 基线差），
  所以"覆盖率 0.846 判定吞字"要打折看：比参照低 0.045~0.053，不是真吞字。

## 五、分块规则（不是 2600 字）

2600 最早来自**员工原话**"elevenlabs 上限 2600 字，员工得手动拉到底截断"。
10-05 案例拆解实测：EL 按**音频时长 ~250 秒**切，不是按字数
（男 4091 字切在 2157 字 = 258s；女 3429 字切在 1879 字 = 250s）。
→ 现网 `TTS_CHUNK_MAX_SECONDS=250`，块字数上限 = 250 × 实测 cps × speed；
尾块过短才回退等分。2600 只剩兜底常量。

⚠️ **cps_lock 脏数据事故（2026-10-13）**：`yohan_male.cps_lock=4.01`
（实测 7.05）→ 4595 字被切成 5 段（每段 ~140s），而 EL_male 同长度只切 3 段。
已在 `app/pipeline.py` 加 `CHUNK_CPS_MIN/MAX=6.0/10.0` 钳位（需重启生效）。

## 八、操作要点

- `ssh yuyin`；代码 `/mnt/tts/projects/qwen3-tts`（**非 git 仓库**，靠 rsync 同步本地）；
  数据 `/mnt/tts/data`；成品 `/mnt/tts/output/{任务名}/`；模型 `/mnt/tts/models`。
- ⚠️ 服务器时区 **UTC**，cron / 日志时间都要 +8 才是北京时间。
- 3090 UUID `GPU-b67eee2c-c672-6915-910d-617c62abebee`；3060 `GPU-94853612-464c-...`。
- 判活必须**真跑一条生成**（服务"活着"≠能出片）；改 py 要安全重启，别打断员工任务。
- 自测账号 `selftest`（**不动** admin / 이민정）；users 启动时加载，加账号要重启。
- 停顿目标必须用**可听口径** `pause_targets_audible.json`（能量口径，非 VAD 口径）。
  旧口径把 −40dB 呼吸当停顿，PBA 照它造出 14 个死寂断档。与听觉冲突时**以听觉为准**。
- A/B 片段必须**裸切不 loudnorm**（动态 norm 把 −50dB 停顿泵过阈值，抹平卡顿差异）。
- 后处理链：PBA → slowdyn → EQ → PROSO → 响度闭环 → peakfit；
  环境 `SLOWDYN=1 PROSO_MED=0 PEAK_FIT=1 LOUD_TOL=.15 TTS_PAUSE_TARGET=audible`。
