# 员工生成语音：12项验收清单

目标：与指定参考音频的音色、自然度和财经解说表达尽可能接近；员工仅输入文案、选择男声或女声，其余使用已验收配置。

来源：用户2026-10-09提交的员工生成音频与案例对比要求。以下为验收规格，不代表已经确认所有缺陷存在，也不代表已全部达标。此前版本擅自改写12项并标记部分达标，现予以纠正。

| 序号 | 项目 | 原始要求 | 验证方法 |
|---|---|---|---|
| 1 | 自然度 | 连续讲话自然，减少明显逐字朗读感 | 同文案盲听、3—5分钟连续试听 |
| 2 | 音色 | 尽可能接近参考文件的音色特征与共鸣 | 说话人相似度辅助、母语盲听、频谱对照 |
| 3 | 语调 | 陈述、疑问、提醒、转折表现不同语气 | 固定四类测试句，逐句盲听 |
| 4 | 情绪 | 有财经解说感染力，但不过分夸张 | 重点/风险/开场/结尾对照，主观评分 |
| 5 | 停顿 | 符合韩语语义，不产生机械断句 | 词时间戳、语义边界审核，避免助词/单位断开 |
| 6 | 语速 | 自然快慢变化，不突然加减速 | 同文本逐句时间序列、长音频前中后对照 |
| 7 | 发音 | 符合韩语连音、音变、收音和句末习惯 | ASR辅助与母语核听，ASR不能替代发音判断 |
| 8 | 数字 | 金额、日期、数量、百分比准确 | 规则单测、关键数字逐项核对，不只平均CER |
| 9 | 重音 | 根据关键词与句意突出重点 | 固定重点句盲听，避免全句强调 |
| 10 | 呼吸 | 自然轻微，无异常吸气或过度换气 | 词中/句间呼吸定位及耳听，不人为堆呼吸 |
| 11 | 连续性 | 分段间无明显音色、响度、节奏断层 | 拼接边界核听、逐窗音色/能量/音高检查 |
| 12 | 完整性 | 不漏读、不乱读、不重复、不提前截断 | ASR逐段对照、尾句核查、重复检测、EOS/长度监测 |

## 发布门槛

- P0：发音、关键数字、完整性和同说话人稳定；任何关键错误不得以高总分抵消。
- P1：自然度、停顿、语调、情绪、句内节奏、重音。
- P2：呼吸与响度细节，不能通过强压缩或音量放大伪装改进。
- 固定文案、同参考、同采样设置，至少多个随机种子；男/女各验证，再做10分钟长文本。
- 所有12项当前均待这批指定音频的正式验收。物理指标评分不是主观还原百分比。
- LoRA可能改善表达，但不能保证同时解决所有项目；文本规范化、语义分段、完整性回检与局部重生成同样必要。

## 2026-10-09训练诊断

首轮yohan训练的loss下降不能证明提升。复核发现：目标文本未进入条件输入、缺少EOS训练、训练/评测生成模式不一致；比例切片也不是精确文本音频对齐。

已修复训练条件和EOS，并隔离旧检查点。在3090上完成20步有界技术验证：峰值7.97GiB、验证loss8.268。该结果仅证明修正后的训练路径可执行，不证明自然度提升。旧adapter与新技术验证adapter均不进入员工默认配置。

下一步：真实时间对齐与切片质量筛选 → 有界同文案多种子A/B → 检查关键数字/完整性/句尾停止 → 男女人工与自动回归 → 通过后才更新默认配置。

## 2026-10-09 进展：精确对齐已落地

新增 `tools/lora_data_align.py`：用 faster-whisper **词级时间戳**对齐，替换
`tools/lora_data.py` 的字符比例估算。逐句覆盖率 < 0.75 的句子直接丢弃，不进训练集。

试跑（前 4 条案例）：train 44 片 / 10.6 分钟，val 11 片 / 2.6 分钟；
切片句覆盖率 min 0.75 / 中位 0.81；抽样 ASR 回检 **CER 中位 0.1189**（噪声底 0.2227），
**空转写 0 条**。回检口径：空转写一律判失败，不当作 skipped 放行。

⚠️ 与旧数据集的 CER（0.1094，10 条抽样）**不可直接比优劣**：抽样条数与切片长度都不同，
且 CER 检不出边界漂移。新数据集的可信度来自"边界取自真实时间戳"，不是靠 CER 更低。

新增 `tools/ab2.py`：两阶段实验驱动（阶段一案例对标含 case_id 双条件 + 多 seed；
阶段二未见文案迁移，默认不带 case_id）。判定顺序固定为：
**完整性/关键数字 → 分项指标 → 人工盲听**，物理总分不得抵消关键错误。

详见 `docs/两阶段还原实验与最佳方案-2026-10-09.md`。
首轮 LoRA 仍未证明提升，adapter 不进入员工默认配置。
