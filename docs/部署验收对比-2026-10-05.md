## 2. 部署中踩到的三个坑（均已写入「从零部署与迁移.md」§8b）

### 坑 1：torch wheel 别用国内镜像

| 源 | 实测速度 | 554MB 耗时 |
|---|---|---|
| mirrors.aliyun.com/pytorch-wheels | ~100 KB/s | 约 1.5 小时（实测卡死）|
| **download.pytorch.org/whl/cu130** | **6.5 MB/s** | **约 85 秒** |

### 坑 2：双显卡编号是反的，`CUDA_VISIBLE_DEVICES` 必须写 UUID

```
nvidia-smi:  index 0 = RTX 3060 (12G)   index 1 = RTX 3090 (24G)
torch:       device 0 = RTX 3090        device 1 = RTX 3060   ← FASTEST_FIRST
```

写序号必踩错卡。现用 `GPU-94853612-464c-9177-c374-a9a82e321229`。
**唯一可靠的验证方式是看 nvidia-smi 哪张卡有占用**（实测 3060 4241 MiB / 3090 9 MiB）。

### 坑 3：🔴 ASR 内容回检静默失效（最危险）

现象：**所有任务 `CER=0.0000` 且通过，日志无任何报错**。两个成因都被
`asr_check.py` 的「异常一律降级为跳过」吞掉了。

| # | 成因 | 对策 |
|---|---|---|
| 1 | 服务 `User=root`，模型缓存在 `/home/zheng/.cache` → `local_files_only=True` 直接抛 `Cannot find cached snapshot` | 缓存迁到 `/mnt/tts/models/asr`，unit 里 `HF_HOME` 钉死 |
| 2 | faster-whisper ≥1.2 与 av ≥19 不兼容（`metadata_errors` 参数已移除）→ TypeError → 转写返回空串 | 不传文件路径，改用 soundfile 读 ndarray（`_read_16k`，含自重采样到 16k）|

补充：`av<15` 无法降级（无预编译 wheel，退回源码编译并缺 `libavformat-dev`）；
ctranslate2 要 `libcublas.so.12` 而本机是 CUDA 13 → **ASR 必须走 CPU/int8**。

**验收铁律**：任务 `stats.asr_skipped` 必须为 **0**，且 CER 是**非 0 真值**。
看到任何任务 CER 恰好为 0 = 回检坏了，不是发音完美。

修复前后对照（同一任务）：

| | 修复前 | 修复后 |
|---|---|---|
| CER | `0.0000`（假）| **`0.2000`（真）** |
| asr_skipped | 1 | **0** |

### 4.3 判读

- **历史对照**：2026-09-29 同文本终测时，节奏类（D/E/F）落后 17~20%。
  本轮男声 D/E/F 全部收敛到 5% 以内，**E 几乎完全一致**（34.56 vs 34.57）。
- **男声短板**：C 能量动态 −15.2%（轻重对比偏弱）、A 句内动态偏高 +12.9%。

  需确认是重建音色所致还是后处理退步 —— **列为下一轮第一优先级**。
- 两性别句段数都偏多（+7.8% / +14.5%），仍是「偏碎」的老倾向。
