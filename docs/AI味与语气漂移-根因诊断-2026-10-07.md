# 「AI 味重 / 语气不自然 / 说着说着飙方言」根因诊断

> 2026-10-07　员工反馈（r23 最新版）：
> 「语音好了不少可是还是 ai 味比较重。语气不太自然，然后这语音模板怎么
> 说着说着飙方言啊，语气就变了」
>
> 本文回答**「和案例对比到底区别在哪」**。诊断工具：`tools/drift.py`、
> `tools/sentvar.py`、`tools/acchk.py`、`tools/dump_cmp.py`。全部带案例对照组。

---

## 0. 结论（先给）

| 员工的话 | 量化结论 | 是否真的存在 |
|---|---|---|
| **「飙方言」** | 逐窗 Whisper 语言自动检测 **78 窗全 ko**，非韩文字符占比 0.000~0.001（案例 0.000~0.001，**完全一样**） | ❌ **不存在**。内容没跑飞，是听感 |
| **「语气就变了」** | 句级 f0 中位我们比案例**低 4.5~9.9%**；30 s 窗 f0 漂移是我们比案例大 **1.03~1.31×**，voiced **1.18~1.57×** | ✅ 存在，但是**基线偏低**，不是"换了个人" |
| **「AI 味 / 没感情」** | **句间能量没有段落结构**：慢变占比只有案例的 **0.38~0.73×**，lag-1 自相关我们 **−0.19~−0.22**（逐句反相抖）vs 案例 **+0.04~+0.17**（慢变） | ✅✅ **头号病因**，五例全同向 |
| （未提）**音色** | tilt sd 我们 0.37~0.39 vs 案例 0.57~0.68（**0.45~0.66×**）；LTAS 距首窗我们 0.96~1.59 vs 案例 1.50~2.04 | ✅ 我们**过于恒定**，也是 AI 味来源 |

一句话：**问题不是"整体不像案例"，而是"我们太恒定 + 起伏的时间结构错了"**。
案例如真人一样在几十秒尺度上成段地轻/响、共鸣缓慢变化；我们是每句一个电平、
还逐句反相抖动，起伏全堆在"句到句"这个错误的尺度上。

### 顺带排除的两个嫌疑（省掉一大笔工作）

- ❌ **分块边界跳变 / context stitching 不成立**。块间 sd 只有块内的
  **0.08~0.39 倍**（8197d9 三块 f0_med 181.9 / 182.9 / 175.7，块间 sd 3.20 vs
  块内 8.13）。漂移发生在**块内部连续渐变**，不是边界。做了 stitching 也没用。
- ❌ **"飙外语"不成立**（见上），ASR 那一路可以关掉了。

彻底转到「韵律结构」。

## 3. 🔴 头号病因：句间能量没有段落结构

### 3.1 现象：30 s 窗响度，我们是一条直线

| 案例 | rms_db 窗间 sd 我们 | 案例 | 倍数 | rms_db 极差 我们/案例 |
|---|---|---|---|---|
| 1a6c20 | 0.17 | 0.86 | **0.20×** | 0.69 / 2.99 |
| 00b6a4 | 0.17 | 0.53 | **0.32×** | 0.58 / 1.89 |
| ba24c0 | 0.21 | 0.54 | **0.39×** | 0.71 / 2.09 |
| 8197d9 | 0.24 | 0.87 | **0.28×** | 0.96 / 3.86 |
| 6cdd25 | 0.21 | 0.59 | **0.36×** | 0.76 / 2.53 |

两边整体响度几乎一样（均值我们 −25.4 / 案例 −24.9 之类，差 ≤0.5 dB），
有声占比也几乎一样（voiced sd 0.01~0.04 两边同量级）——
**同样的有声比例、同样的整体响度，案例 RMS 在 30 s 尺度上起伏 2~3 dB，我们是直线。**

### 3.2 定位：差别不在"起伏的量"，在"起伏的时间结构"

逐句量（`tools/sentvar.py`），看序列的 lag-1 自相关与**慢变占比**
（MA(10) 后 sd / 原 sd；白噪声 ≈ 0.32，慢变 → 1）：

| 案例 | 句级能量 sd 我/案 | **慢变占比 MA10 我/案** | 倍数 | **能量 ac1 我们** | **能量 ac1 案例** |
|---|---|---|---|---|---|
| 1a6c20 | 1.05 / 1.53 (0.68×) | 0.20 / 0.54 | **0.38×** | **−0.29** | +0.20 |
| 00b6a4 | 1.12 / 1.20 (0.93×) | 0.18 / 0.41 | **0.45×** | **−0.18** | −0.04 |
| ba24c0 | 1.15 / 1.40 (0.82×) | 0.18 / 0.43 | **0.42×** | **−0.32** | +0.06 |
| 8197d9 | 1.17 / 1.62 (0.72×) | 0.28 / 0.54 | **0.52×** | **−0.20** | +0.17 |
| 6cdd25 | 1.08 / 1.31 (0.83×) | 0.23 / 0.31 | **0.73×** | **−0.22** | +0.06 |

**我们 0.18~0.28 比白噪声基准 0.32 还低**（ac1 为负 = 逐句反相交替：
这句响、下句就轻）；案例 0.31~0.54 明显高于白噪声（ac1 为正 = 慢变）。

这正好解释 3.1：我们的逐句抖动被 30 s 窗内平均**互相抵消**，
案例的慢变被平均**保留**。同样的句级 sd，一个"抖"一个"起伏"。

### 3.3 已排除伪影

`tools/acchk.py` 复核（剥掉句内静音、**只算有声帧**的电平，并同时看句长）：

| 案例 | 有声段电平 ac1 我们 / 案例 | 句长 ac1 我们 / 案例 | corr(电平,句长) |
|---|---|---|---|
| 1a6c20 | −0.21 / **+0.17** | +0.02 / −0.06 | −0.10 / −0.01 |
| ba24c0 | −0.19 / **+0.04** | −0.01 / −0.03 | −0.28 / −0.23 |
| 8197d9 | −0.22 / **+0.13** | +0.14 / +0.00 | −0.20 / −0.10 |

- 句长 ac1 两边都 ≈ 0 → **不是"判句长短交替"造成的**
- 换成"只算有声帧"口径后结论不变 → **不是"句内静音拉低均值"造成的**
- n≈150 时 ac1 的标准误 ≈ 0.08，−0.2 是 ~2.5σ → 显著

### 3.4 编码链里没有压缩器（平坦是我们自己生成出来的）

成品编码链只有 `atempo / 音色EQ / aresample / 空气感 / alimiter / volume`
（`app/server.py:1437-1510`），**没有任何 compand / dynaudnorm / loudnorm**。
`alimiter=limit=0.79` 在这个 ffmpeg 版本里是**纯增益**（陷阱 #23，实测输入
0.771/0.386/0.154 输出一律 +2.05 dB），也不会压平。
→ 平坦是 **Qwen3-TTS 生成端固有**（每句从同一参考音频起头、codec 归一化），
后处理既没造成它、也还没修它。

## 7. 修复方案（按推荐度排序，用户定）

### 方案 1 ⭐ 慢尺度能量轮廓重建 —— 新建 `app/slowdyn.py`

- 逐句算有声帧电平 → 用 MA(~15 句) 分离**慢变成分** `s` 与**快变成分** `d−s`
- `d' = mean + k_slow·(s−mean) + k_fast·(d−s−mean)`
  - `k_slow = 案例慢变sd / 我们慢变sd` ≈ **2.0~2.7**（需限幅，建议 ≤2.5）
  - `k_fast = 案例快变sd / 我们快变sd` ≈ **0.8~1.0**（略压逐句抖动）
- 换回逐句增益，句边界 30 ms crossfade，放在 `dyn.expand` 之后 / PROSO 之前
- **预期**：修"AI 味/没感情"；30 s 窗 rms 结构对齐；
  且**顺带抬真峰值**——只抬部分句子时 LUFS（均值）不动、峰值（最大值）上升，
  这是绕开「峰值/CF 不可修」（响度归一 1:1 抵消）**唯一合理的路径**
- **风险**：① 抬响句可能撞 `alimiter`(−2.05 dB)，需留 headroom，先离线标定
  ② 改变能量分布上端会漂移相对阈值 VAD（r24 软削波就是这么崩的 E/F），
  但慢变 ±1.5 dB 比软削波温和得多，p25 不受影响，需实测

### 方案 2 f0 基线对齐 —— 复用 `app/proso.py` 的 PSOLA

- 全局乘 `k = 案例句级 f0 中位 / 我们` ≈ **1.05~1.11**（分性别取中位数）
- 只做全局缩放，**不动 A/E 形状**（现有 PROSO 只拟合 A/E，从不管基线 —— 这就是漏掉的原因）
- ⚠️ 陷阱 #4/#10：Praat 口径 ≠ pyin 口径，系数必须**实测反推校准**，不能照搬

### 方案 3 音色慢变注入（优先级低）

- 案例 tilt sd 0.57~0.68，我们 0.37~0.39 → 注入缓慢的 EQ/共振峰漂移
- 风险：与现有固定音色 EQ 冲突，可能引入金属感

### 方案 4 不动后处理，转 SFT

- 后处理已到顶（r21/r24 连续证伪），唯一能跨数量级的路是**说话人微调**
- 男声同人数据 ~34 分钟已达门槛，CosyVoice3 官方训练脚本已跑通
- 路线图见 `docs/说话人微调路线图.md`

**建议：先做 1+2（都是低风险后处理、可测、可回退），同时推 4。**

## 8. 新增度量陷阱（长期有效）

- **#24 均值类指标抓不到"内部前后不一致"**：整段一平均，漂移就被抵消。
  查"说着说着就变了"必须**切窗/切句看序列**，且**必须有案例对照组**。
- **#25 "起伏"要看时间结构，不能只看 sd**：同样的句级 sd，
  逐句白噪声（ac1≈0，MA10≈0.32）听感是"抖"，慢变（ac1>0，MA10>0.5）听感是"有起伏"。
  我们的能量序列 ac1 是**负的**（−0.19~−0.22），比白噪声还抖。
- **#26 块间 sd 会被块内平均稀释**：判断"有没有边界跳变"不能比块间 vs 块内 sd，
  必须看**逐窗序列**在边界处有没有台阶（`drift.py` 的 `series_line`）。
- **#27 Whisper 语言自动检测是抓"飙方言"的唯一手段**：六维韵律和所有声学指标
  都抓不到内容跑飞；但反过来说，**查完了发现没跑飞就该立刻转向韵律**。
