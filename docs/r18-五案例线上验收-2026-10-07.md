## 1. 🔴 关键发现：r15 那段「yohan 是另一个音色」是错的

`server.py` 里 r15 留下的注释写着：yohan 3 例是「另一个音色」，所以
`_bench_cases()` 只认打了「标杆」tag 的案例（只有 2 例），
响度 / PROSO / 停顿目标**全都只用这 2 例拟合**。

**那是凭 LUFS 差 0.7 dB 猜的，从没做过说话人核验。**
r19 用 CosyVoice3 自带 campplus 提嵌入实测（`/tmp/spkchk.py`）：

| | 标杆男 | 标杆女 | ba24c0 | 6cdd25 | 8197d9 |
|---|---|---|---|---|---|
| **标杆男** | 1.000 | 0.328 | **0.935** | **0.943** | **0.924** |
| **标杆女** | 0.328 | 1.000 | 0.309 | 0.321 | 0.319 |
| ba24c0 | 0.935 | 0.309 | 1.000 | **0.971** | **0.957** |
| 6cdd25 | 0.943 | 0.321 | 0.971 | 1.000 | **0.949** |
| 8197d9 | 0.924 | 0.319 | 0.957 | 0.949 | 1.000 |

同人阈值 0.75 / 不同人 < 0.55 → **4 个男声是同一个人**。三个后果：
1. ✅ 用 `EL_male` 生成 yohan 3 例是**对的**，对账有效
2. ✅ 把它们并进目标值不是「稀释」，是同人多样本、估计更稳
   （响度中位数 −24.3 → −25.0；停顿样本 162 → 688，后者本就是原设计意图）
3. ✅ **男声同人数据 ~34 分钟，已达微调 SFT 门槛**（见 `docs/说话人微调路线图.md`）

### 代码改动
```python
# 默认从「标杆」改成空 —— 同性别 + source 白名单全收
CASE_BENCHMARK_TAG = os.environ.get("TTS_CASE_BENCHMARK_TAG", "").strip()
```

tag 很容易忘打，结果就是「加了案例却不生效」。

### 为什么标杆男掉了 1.61
LUFS 目标从 −24.3 改成同人 4 例的中位数 −25.0 → 标杆男偏 0.7 dB（11.7%）。
**用中位数是统计上最优的**：
| 目标 | 4 例平均 LUFS 偏差 |
|---|---|
| −24.3（旧） | 0.575 dB |
| −24.875（均值） | 0.288 dB |
| **−25.0（中位数）** | **0.225 dB** ✅ |

标杆男让 1.6 分，换 yohan 3 例共 +6.0 分，且过拟合从 4.24 降到 0.84。

### 为什么标杆女掉了 1.14
女声只有 1 个案例，目标值**没变**。掉分全在 **F 停顿熵 20.9%**（0.618 vs 0.782）——
停顿 reshuffle 带随机采样，属于**生成随机性**（记忆 §6-7：单次波动可达 ±12 点）。
