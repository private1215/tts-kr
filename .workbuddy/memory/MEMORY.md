## 🔴🔴🔴 三问结论（2026-10-20，已写进 `out/三问深挖-202610190902.md`）
1. **模版比成品脏 = 测量伪影**：模版 EL_female.wav **原生 24kHz click = 0 处**，重采样 16k 后
   出现 7 处（2:3 非整数比重采样制造 |Δ|≥0.30 假 click）。模版是 EL 原始素材、从不做后处理；
   EL 标杆同口径 119 处 click 事件 vs 我们成品 0 处。15s 窗口算「每分钟」统计不成立（Poisson CI 太宽）。
2. **数字念读**：48 个数字表达 40 个数值全对。员工 29/44/64/115s「吃字」全是 whisper 数字伪影；
   `삼십일만육천원`(316,000)→ASR「30일 16,000원」已用**对照实验**定罪（干净单句同样听错 = ASR 伪影）。
   **唯一真问题 = 文案病态数字** `한 사쩜사퍼센트`（1 与 4.4 组不成合法数，TTS 忠实念出）→ 改文案即可。
3. **句末「嗯」= 浊音自然衰减残留，不是杂音，我们比 EL 还干净**：
   同口径（后段前须 >0.05s 静音）我们严 2.15/分 < EL 3.40/分、宽 6.24/分 < EL 10.32/分。
   🔴 **上一轮「我们 5.99 vs EL 3.89 = 1.55×」是口径 bug，已作废**（漏了「后段前 >0.05s 静音」条件）。
   基频延续（比值 0.82~1.30）+ 低频占比 0.64~0.68 + 我们 67% 衰减/0% 上升 → 纯衰减尾巴。
   能清（tailclean53b2 可到 0.64/分）**但不该清**：物理不可闻 + EL 更密 + 严禁清零 + 伤音色风险。
   **EL 舒服与句末嗯无因果**（EL 更密却舒服）→ 员工听到的「嗯」另有所源（疑文件头孤立段）。

## 🔴🔴 headfix 阈值（v3.5，13 样本验证无一批判错）
起音碎片 vs 真实首词，**只有「间隙时长」能分开**：
- 真碎片（该切）：20ms/510ms、20ms/490ms、60ms/270ms、70ms/560ms、150ms/630ms、30ms/410ms、20ms/260ms
- 真实首词（不该切）：90ms/120ms、100ms/140ms、150ms/170ms、170ms/150ms、50ms/190ms、110ms/50ms、130ms/40ms
→ **gap ≥250ms**（真碎片最小 260 / 真词最大 190）。碎片时长单独用会误伤（真碎片 150ms vs
  真词 90ms 交叉）；**间隙底噪 dB 无区分度**（两边都 -52dB 左右）。
⚠️ v3.4 的 150ms 会把 `한 퍼센트` 的实词「한」(170ms+150ms) 切掉 —— 判据是
`TTS_HEADFIX=0` 重跑同一条：未切 dur 4.4s 且 ASR 含「한」，开启态 4.18s 且「한」消失。
⚠️ whisper 会把「한 퍼센트」规范化成「**1%**」—— 别据此判「丢词」，用**时长差**判。

## 常用操作坑（最高频）
- 🔴🔴 **补丁自检必须 `compile()`，不能用 `ast.parse()`**（不走符号表，抓不到 `await` 作用域错误）。
  给 `run_job()` 里的嵌套函数插 helper，缩进必须**同为 4 空格**，否则截断外层 async → 服务启动即崩。
- 🔴🔴 **插 helper 后必须跑 L1 实测，不能只信 audit53**（它只查"字符串在不在"，查不到"没被执行"）。
  两招它都全绿：① `return _cf(*_eq(...))` 解包二元组少收参数 → TypeError → 回退 raw；
  ② `if len(_y) != len(audio): return audio` —— **firequalizer 输出比输入长 filter_size-1 样本**
  （16k 长 320 = 20ms）→ 每次退回。修：helper **只返回 audio**；长度差**居中裁剪**，差 >0.5s 才真退回。
- 🔴🔴 **改完 `voices.json` 必须重启 qwen-tts**（任务结束时把内存音色表写回磁盘，冲掉新加音色）。
- 🔴🔴 **app/ 下扁平导入**：`from app import xxx` 启动即连崩 7 次。
- 🔴🔴 **服务日志在 `service.log`，不在 journalctl**；`sudo -n journalctl` 需密码时**静默返回空、不报错**。
- 🔴🔴 **产物目录会加 `-N` 后缀**：`find_out` 取 mtime 最新；`glob(title+"*")` 会抓旧目录。
- 🔴🔴 **faster_whisper 必须 `local_files_only=True`**（无外网 → 静默挂死 4 分钟）；**不能传文件路径**
  （av 不兼容）→ ffmpeg 降 16k，soundfile 读 ndarray 再 `transcribe`。
- 🔴 `voices/sources/` 是 root 属主 → 切片放 `voices/<name>.wav`。`voices.json` 是**扁平字典**（键=音色名），
  写入前照抄完整字段：path/label/ref_text/sr/dur/engine/gender/bench_case/origin/src_case/src_speaker/src_dur/clip/cps_lock/cps。
- 🔴 反馈台 `items.json` 必须 `{"items":[...]}`（裸 list 打不开）；前端选项**单选**；
  **每个有 file 的 option 都渲染播放器** → 只让第一个带 file。
- 🔴 `pkill -f "[x]xx"`；缓存名用**全路径 hash**（男女标杆都叫 merged.wav）。
