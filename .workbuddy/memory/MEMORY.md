## 核心目标
替代 ElevenLabs（**EL**）省钱。验收：同一条韩语文案，我们 vs EL，员工听不出差别。
- 案例库 36 条**全是 EL 生成**。仅 2 个声音：SOLA 女 22 / yohan 男 13。`EL_male`/`EL_female` = 15s 标杆参考，**音色源 == 质量标杆**。

- 循环：自检→修复→验证→更新题库→同步服务端并核对→Git 提交。验收只看长篇。

## 🔴🔴 分级验证铁律
| 级 | 长度 | 用途 |

## 已定案结论（别再试）
- F0 单独验收（campplus 看不见音高）；F0 按时间轴分窗变调（`--pitch-win 15.0`，引擎长篇漂 +11%）。
- 测量必须全篇/中段，不能只测前 60s。
- 变调只用 `asetrate+aresample+atempo`，禁 rubberband；语速锚点只用字/秒；60–150Hz 变调后 EQ 补不回。
- 分块背锅已证伪（1 vs 2 块相似 0.9947）。韩语数字不能信 whisper-small。
- mp3 会抹掉硬切 → A/B 素材必须 wav + 归一。响度归一**不会**抹平硬切（静态 volume）。
- 掉帧/卡顿已修：`app/declick.py`（<−100dB 段整段换环境声；第44轮修掉过零漏洞）；
  `pause_clean_v3.py` seed 已按位置派生。
- 第31轮：双重 WSOLA 已融合成单次 atempo（Σz² 72.2→27.1）；窄带 EQ 会摧毁平坦度（几何均值对陷波敏感）→ 追单频 z 分必须盯平坦度。
- ❌ 已证伪：mp3 压高频、换 soxr、缺频段（±13% 内）、慢调制补起伏（停顿中位仅 0.07s）、抬停顿底噪（相对阈值跟着抬）。
- ❌ 断句异声（员工三批都提）里已证伪：**多念字**（CER 0.038、零 insert）、
  **音高拔高**（短音相对上下文偏低 −37~−216Hz）、**短音变多**（29.6 vs 28.9 个/分）、
  **局部顶起过多**（真 EL 基线 merged.wav 30.5 处/分，我们 25.1 —— 我们比 EL 还**少**）。
- ❌ 断句异声的八条失败修复（都别重踩）：软噪声门压拖尾（release 117→152ms、电平掉 2.6dB）、
  填房间底噪（旧）、句末淡出、元音起音柔化（z10 三票全「差不多/都不行」）、
  **分段压顶起（z43 三票全 D/C → 第五次失败）**、迭代压顶起（Σz²→72.0、发声占比 −5.79σ）、
  连续平滑增益（太弱 25.1→21.4）、句末突起压制（顶起密度没降）。
- 🔴🔴🔴 **断句异声的真根因 = 句间停顿「往下沉」（2026-10-16 定案，见下节）**

## 🔴🔴🔴 断句异声的真根因：句间停顿「往下沉」（2026-10-16 定案，已上线）
同文案绝对秒对照（EL 女声原声 52727ec ↔ 我们现役 198.6s 成品）：

| | EL 原声 | 我们现役 | 修后 |
|---|---|---|---|
| 停顿帧中位 | −51.8dB | −51.9dB | −51.3dB |
| p5 / p10 | −60.5 / −58.7 | **−73.5 / −62.4** | **−59.1 / −57.9** |
| min | −98.5dB | **−240dB** | −86.5dB |
| <−100dB 帧 | **0** | 32 | **0** |
| 深谷(<−60dB,≥40ms) | 8 段 | 20 段(中位 −76.7) | 0 段 |
| L1 Σz² / 平坦度 | — | 32.2 / +3.85σ | **27.8 / +3.22σ** |

- 机理：EL 的停顿「衰减到 −52dB 就**平躺**在房间底噪上」；我们的停顿「穿过 −52dB 继续
  **下沉**」，沉到 −73dB 甚至数字零。沉下去后语音再起来落差从 ~30dB 变成 50~220dB
  → 耳朵把断口紧邻的那一两个音节凸显出来 = **「突然蹦出来的一声 / 额 / 啊」**。
- 🔴 **员工点名 3 处 ↔ 深静音谷，3/3 精确命中**（z43 题1 切自 90s 起→员工说「5 秒有额」=95.50s；
  题2 切自 130s 起→「1 秒有啊」=131.28s【数字零】；题3 切自 160s 起→「10 秒有啊」=169.93s）。
- ✅ 修法 `app/silfloor.py`（第44轮上线）：**加法式地板** `out = seg + tone*g`，
  门限 −58dB、目标 −52dB、段长 ≥60ms、上下文高出 >12dB 才算停顿；底噪优先取自身帧拼接。
  只会抬高、绝不压低 → 物理上不可能挖新坑。长度/峰值都不变。
- 🔴🔴 **两条写死的硬规矩**（旧 `apply_silfix` 就是这里栽的）：
  ① 严禁 `where(|tone| > |seg|, tone, seg)` 这种**逐样本取较大** —— 噪声过零时 |tone| 掉到
  |seg| 以下，数字零原样漏过去（declick 漏 32 帧就是这个）；
  ② 底噪电平必须**按 RMS 归一**，峰值归一会让 −52dB 实际变成 −68dB（填了但更深）。
  ③ 淡入淡出必须**交叉淡化** `tone*w + seg*(1-w)`，只写 `tone*w` 等于在段两端亲手挖坑。
- `app/declick.py` 同步修掉过零漏洞（floor 模式改成整段替换、去掉会挖坑的淡入淡出）；
  `TTS_SILFLOOR=0` 可一键关掉。位置：**declick 之后、libmp3lame 之前**，
  且必须在 `_legacy_post` 快路径里（NEW_ENGINES 会绕过 roomtone）。
- 出题 z44（5 题）：断句裁决 ×3（覆盖员工三处点名）+ 底噪护栏（问停顿处有没有沙沙声）+ 控制。

## 🔴🔴 变调（asetrate）吃掉 2/3 音色（2026-10-16 定案）
- 口径：`spkchk.embed()` campplus 16k nwin=12，同人阈值 **0.75**，对比必须同素材同长度。
- 账本：EL 上限 0.9628 → 裸推理 0.8530 → 变调后 **0.6739**（−0.177，62% 损失）→ 清洗/EQ 只 +0.006。
- 机理：asetrate 把 F0 和**共振峰**一起搬 R 倍，共振峰 = 说话人身份。剂量-反应随 R 单调恶化。
- rubberband 更差（0.44~0.55）。「后处理到顶」「campplus 看不见音高」均已被推翻。
