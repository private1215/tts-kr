### 分级定义
| 级 | 长度 | 成本 | 能判什么 | 用法 |
|---|---|---|---|---|
| **L1 快筛** | 15~30 秒 | **几秒** | 改动**有没有生效**、链路通不通 | 每次改动都跑 |
| **L2 短篇** | 60~120 秒 | 十几秒 | 大改动方向筛查（跑3次取中位） | 关键改动 |
| **L3 长篇** | ≥3 分钟，**最好 ≥5 分钟** | 7 分钟+ | ✅ **唯一可信的质量验收** | 验收节点 |

### 🔴 短片为什么不能当验收（实测，非推理）
1. **不自洽**：同配置 18 秒连跑 7 次，Σz² = 190.6/235.9/**753.2**/425.3/426.8/650.0/527.4
   → **波动 4 倍**。连"同配置两次生成"都差这么多。
2. **系统性偏差（致命）**：短片 `4k~8k` = **0.0034~0.0070**，EL = 0.0129，**低 40~60%**；
   长篇 496 秒 = 0.0145（比值 1.12）。
   → 18 秒里说话人没进入稳定状态，高频（齿音/气息）根本没铺开。
   🔴 **拿短片调高频 = 照着假数据改**，会得到完全相反的结论。

### ✅ 完整表述（两条铁律合起来，不矛盾）
- **验收**：只用长篇（≥3分钟）
- **调试**：先用短片快速筛，短片**只能判"生效/没生效"，不能判绝对分**
- 🔴 **禁止跳级**：我 10-15 上午直接提交 496 秒长文（花了 7 分钟），
  拿到「Σz²=13.1 极好」——**那只是运气好**（同配置 8197 批是 863）。
  没有 L1/L2 对照，L3 结果无法解读。
- 🔴 L1 的正确用法是 **A/B 相对比较看中位数**，不是比单次绝对分。

### L1 闸门工具 `tools/gate_l1.py`
门槛：时长 8~120s / Σz² 中位<4000 / **4k~8k 比值>0.45** / N 次散布<3.0。
实测 600 字×3 次（69~71 秒）：Σz² 138.7/176.7/23.9，**散布 6.39 倍 → 判「先别上长篇」**。
🔴 **闸门真的能拦住，不是摆设**。没通过就不该跑长篇（省 7 分钟 + 避免照假数据调参）。

### 长文案怎么测「一致性」
`probe_g.py --segments`：跨 30s 窗输出每个维度的**极差%/CV%/跨窗 Σz² 波动**，
跳过首尾各 5%。`probe_g` 已内置：默认全篇口径，<180s 直接打警告。
**长篇的差距看一致性，不是任何单点的绝对值。**
⚠️ 20s 尺度上 **EL 标杆自己都能拿 Σz² 61~240** —— 这就是旧口径荒谬之处。

## 「闷」的真实定位（2026-10-15，实测）
- ❌ **不在静态频谱坐标轴上**：新测 HNR（谐噪比）、频谱质心、F1/F2 轨迹
  （`tools/muffle_diag.py`，此前从未测过），我们**全部落在 EL 分布内**。
  加更多静态维度找不出问题。
- ✅ **主因 = 150~300Hz 既不足又极不稳定**。同一文件沿时间轴分窗测该频段：
  | | 中位 | 极差 |
  |---|---|---|
  | EL 标杆 | 0.2495 | **16%** |
  | 我们 | 0.1901 | **47%** |
  46% 的内部起伏 = 听感上忽闷忽亮，本身就制造"不像真人"。
- 🔴 **现役男声 EQ 在反向操作**：superequalizer 第 5 档（**262Hz**）=`1.178`(+1.4dB)、
  第 2 档(92Hz)=`1.524`(+3.7dB)，但实测该频段**不足**。
  这组 EQ 是 r20/r25e 按 LTAS 拟合的，**当时 σ 被离群值撑大 → 补偿量系统性偏小**（历史欠债）。
- ✅ **单档干预实测有效**（同一 20s 切片）：
  不加=236.8 → **+262Hz 1.178 = 110.8** → **`5b=1.300:4b=1.200` = 58.8（落进 EL 分布）**
  → `5b=1.450:4b=1.250`=128.3（过量）。**有明确甜点区，过量同样有害。**
- ⚠️ 这是**离线候选，不是上线结论**。必须先做受控实验（同文案生成 3 次，
  确认 Σz² 散布 < 收益），并检查 60~150 是否被连带抬起（历史：抬低频会抬底噪）。
  底噪斜率那次就是离线漂亮、端到端翻车。

## 验证体系缺口（2026-10-15 新增）
🔴 **缺「自洽性」角度**：同配置、同文案连续生成 3 次，看指标散布。
   记忆里已知"两次生成 Σz² 48.7 vs 56.7"，但从未系统化。
   **若散布 > 改动收益，任何单次对比都不该下结论**——这条要变成硬门槛。
🔴 **时域维度几乎空白**：验收只有 9 个静态标量 + 语速(字/秒)。
   **停顿结构(数量/时长分布/长停顿占比)、能量包络起伏、语速局部方差** 从未进过验收。
   而"闷"被证明不在频段轴上 → 时域是下一个必查战场。

🔴 **语速锚点只能用「字/秒」（跨文案可比）**：EL 实测 **女 7.45 / 男 8.37**。
   绝不许用「音节核/秒」（峰值/发声秒）当固定目标——它与字/秒不同量纲，
   2026-10-14 因此把男声只放慢 3~7%，实际需要 14.4%，员工直接判「太快、不像真人」。
   `fix_chain.py --target-cps <值> --chars <字数>`。
   🔴 **`--el` 逐窗对齐同样不可用（10-14 修正）**：它对的也是音节核/秒。
   老记忆说「同文案 EL 逐窗对齐量纲差互抵」只在**同引擎**成立；跨引擎（VoxCPM2 vs EL）
   实测 x8197 走 `--el` 后 8.94 字/秒 vs EL 8.37，快 6.8%。一律用 `--target-cps`。
🔴 **F0 必须单独验收，campplus 看不见音高**（10-14 发现）：
   VoxCPM2/Qwen 男声 F0 **系统性低 15%**（168~172 vs EL 13 条案例 190.5~205.3，
   均值 197.7）；女声正常（OmniVoice 277 vs EL 271~282）。
   变调前后 campplus 只差 **0.004**——它就是看不见绝对音高，这正是「指标高但听着不像」的原因。
   基线常量 `DEFAULT_F0 = {"f": 276.0, "m": 197.7}`（pyin / 16k 口径）。诊断 `deploy/naturalness.py`。
🔴🔴 **F0 要按「沿时间轴的曲线」验收，不能只看中位**（10-14 推翻全局变调）：
   **VoxCPM2 的 F0 在长篇里往上漂 +11%**（169.7→174.7→176.7→190.5→190.5→193.8→184.0→188.3），
   而 EL 是平的（8197 198.3→190.5，极差 19Hz；1a6c 极差 13Hz）。
   按「前 60s」定一个**全局**变调比例 1.213 → 开头正好 197.7，
   **后半段被抬到 222~233Hz（比 EL 高 15%，极差 37Hz）**＝"发尖/发假/感冒音"的主因。
   ✅ 必须**分窗变调**（每窗按自己的 F0 算比例、1:2:1 平滑）：成品极差 **12.5Hz**，比 EL 还平。
   🔴 参考音频无罪：prompt_yohan_1a6c20a6.wav 自身 F0=196.1（=EL），
      **是 VoxCPM2 引擎自己压低了 13.5%**。别再换参考切片。工具 `deploy/f0_drift.py`。
🔴 **凡评估「分窗」处理，测量必须全篇或中段，不能只测前 60s**：
   分窗变调后第一窗比例最大（1.220），前 60s 恰好是最坏样本，
   用它比会**完全掩盖分窗收益**（base_p 与 base_pw 的前 60s 几乎一样，全篇却差一大截）。
   工具 `deploy/band_full.py`（全篇 7 段）、`deploy/eq_search5.py`（统一取 [60s,360s]）。
🔴 **60–150Hz（胸腔区）变调后补不回来，EQ 无解**（10-14）：
   任何 lowshelf/peaking 都会连带抬 150~300Hz（F0 所在段）40%+，那里我们已经偏多，
   L1 反而从 0.093 恶化到 0.120~0.195。别再试了。
🔴 **变调只用 `asetrate+aresample+atempo`，禁用 rubberband**（10-14 定案）：
   rubberband 会把频谱平坦度压掉（0.050 → 0.035，EL 是 0.042），声音过净发假；
   它的 `formant=preserved` 更糟（flat 掉到 0.015，发闷）。asetrate 只是重采样，
   波形结构保得住（flat 0.049、发声段数与 EL 一致）。
   🔴 三步缺一不可：`asetrate=sr*R, aresample=sr, atempo=1/R`。
      漏了 atempo → 时长被压短 1/R（实测 440.9s vs 应 534.8s）。
   变调后频谱被整体搬高，男声 EQ 高频档要从 -4dB 加深到 -9.5dB。
   现役男声 EQ（第五轮网格搜定案，全篇口径 L1 0.178→0.098）：
   `equalizer=f=800:w=1.2:g=-2, highshelf=1500:+2.5, highshelf=2500:-1.5,
    highshelf=4000:-9.5, lowpass=14000`（未变调时 4000 档用 -4）。
🔴 **flat 只有一种合法口径 = `tools/probe_g.py`**（ffmpeg 转 16k + 前 60s + hop256）。
   自写 `librosa.load(sr=16000)` 同参数也能量，但**数值差 30%**（0.0372 vs 0.0487）。
   要跟基线比 σ / 决定上不上线，一律跑 probe_g；自写脚本只配做分段定位。
🔴 **女声成品只生成文案前 1500 字**（`gen_female_prod.py` CHARS 默认 1500）。
   7.55 字/秒与 EL 女声 7.45~7.59 对齐。别拿它跟 EL 全篇（3937 字/525s）比时长，

## 反馈台（出题硬规则）
- 🔴 **每题只问一件事、选项说人话**（嗓子像不像/念得自不自然/能不能直接用/问题定位），
  30秒定位片段分开问；选项是具体现象（"都还是太快""停顿怪""有杂音"），
  不给笼统的"都不行"当唯一出口。**不强制听够时长**——员工凭感觉即可，
  播放秒数被动记录随票落盘（votes 的 play 字段）供认真度参考。
- 🔴 每轮保留一道**隐藏控制题**（同一段音频放两遍问哪段快，正确答案=一样快）。
- 🔴 同一维度下**所有题的 A/B 语义必须一致**（c 轮男声题 A/B 与女声反了，
  导致"都选 A"被误读成"都选旧版"）。
- 🔴 片段必须**换回员工上一轮选中的那条声音**，并带溯源（任务/引擎/文案）。
  c 轮用 `fb2_*` 而非 b 轮选中的 `fb_*_cosy_*`，员工当场听出"不是昨天那些"，信号作废。
- 🔴 修复**只作用于局部**（如分窗变调后半段收益大）时，**同一 A/B 要切两个位置**
  （开头 + 第 5 分钟处）分开问，否则既低估收益、又看不出开头问题解决没有。
- 🔴 切片写完**必须回读 LUFS 复核**：`volume=%gdBB` 多打一个 B 会被 ffmpeg 解析成
  **+18dB**（-8.5 vs -26.5 LUFS），7 个切片全爆表。正确写法 `volume=%gdB`。
