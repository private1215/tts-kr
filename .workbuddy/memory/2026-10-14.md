## 三、停顿怪音根因（铁证链，不是猜测）

1. **女声 v2**：停顿处理模板取「RMS 最低的停顿段」，但全篇 **0 个合格 room tone 候选** → 模板本身带谐波隆隆声，等于把噪声当底噪铺进每一处停顿。
2. **男声 v4**：日志显示「插入 0 处」= **根本没做停顿处理**，VoxCPM2 原始输出 64 处停顿中 60 处脏，其中 13 处是 40-70dB 语音电平的**人声碎片**。
3. **填充词是 EL 同款自然特征，不能清**：80-400Hz 归一化自相关峰 h=0.5-0.93、50-160ms、-16~-29dB 的谐波孤立短段，EL 标杆自身有 52-83 处（= 韩语嗯/啊/네 自然语气填充词）；我们 42/96，密度同量级、电平时长统计无差异。**曾写了 scrub_stray 清除器，拿 EL 同口径一测 EL 自己也被杀 62/105 处 → 立即叫停。**
4. **开头伪影**：只清文件开头 1.5s 内的孤立响段（生成开头伪影，EL 无此特征），已精准清除。

### 验收口径修正（重要，曾据此误判）
停顿「脏不脏」**必须只看中段**（边缘各砍 `max(30ms, 25%)`）。否则 10ms 窗会跨到语音起音沿，产生 8-30dB 的**伪凸起**——v3 初版报 27/59 处脏，修正后女声 0 处。

### 修复链 v3/v5
合成 clean room tone（白噪声 → FFT 整形：LF<120Hz 余弦衰减除 50Hz 电源嗡、HF>5k 缓降到 0.35 → 按每处停顿自身中段 RMS 匹配电平 → 长度不变、5ms 交叉淡化），替换 ≥0.08s 停顿内容。
- 女声 `X2f_v3f`：中段脏 0（EL 女 1）
- 男声 `X1m_v5f`：中段脏 21（**全为起音缓坡测量伪影**，EL 男 66）

**男声残留定性：剩余「脏」是测量伪影，剩余听感来自填充词/短词（EL 同款），不修。**

## 八、⚠️ 5s 细窗速率比对不可信（已证伪，别再据此调 atempo）

想把「逐 60s 窗 atempo」细化到 5s 以自动发现局部节奏异常（`rate_profile.py`）。
结果 82% 窗落在 ±15% 内、中位偏差 9%，但报出 105s 偏慢 60%、180s 偏慢 48% 等离群点。

**拿 ASR 一比对，全是假象**：100-112s 我们在读「타러 갈지…두드려 맞을지」，
EL 已经读到「두드려 맞을지…」——两边存在 **1~3 秒的文本漂移**，
同一时间点说的不是同一句。两边字符/秒实测 5.58 vs 5.58、5.25 vs 5.25，几乎一致。

🔴 **纪律：细粒度（≤5s）速率比对必须先用 ASR 做文本对齐，
时间比例插值在存在秒级漂移时完全不可用。**
结论：**不存在系统性语速问题，不要再动 atempo。**

## 十七、🔴 男声 F0 系统性塌陷 15%（本次最大发现，10-14）

**现象**：员工那条真实文案（job `cf9d187252f8`，3881 字）跑在 **cosyvoice3** 上被判
「开始就能听出来是机器人」。排查时新写了 `deploy/naturalness.py`（韵律自然度诊断），
一测发现：

| 来源 | 男声 F0 中位（pyin / 16k / 前 60s） |
|---|---|
| EL 男声 13 条案例 | **190.5 ~ 205.3**（均值 197.7） |
| EL_male 参考音频 | 193.8 |
| cosyvoice3（员工听到的） | 190.5 ✅ 正常 |
| Qwen3-TTS | 173.7（低 12%） |
| **VoxCPM2** | **167.8 ~ 171.7（低 15%）** |

两篇不同文案复现（cf9 171.7 / x8197 171.7），**稳定差 ~30Hz**，不是抖动。
女声**没问题**：OmniVoice 277.3 vs EL SOLA 271.0~282.1，落在区间内。

**为什么之前一直没发现**：campplus 音色相似度**对绝对音高不敏感**
—— 变调前后只差 0.004（0.8548→0.8583 / 0.9014→0.9050 / 0.8788→0.8825，三个参照同向）。
指标盲区正好解释了「campplus 高但员工听着不像」。

**修法**：`fix_chain.py` 新增 `--pitch / --target-f0 / --no-pitch`，
用 `rubberband=pitch=<ratio>` 变调（只升音高、不改时长）。默认自动：
`DEFAULT_F0 = {"f": 276.0, "m": 197.7}`，比例 = 目标 / 实测，钳 [0.90, 1.30]。
**结果**：x8197 成品 F0 **198.3 = EL 同篇 198.3**（精确命中）；cf9 196.1（差 0.8%）。

### 四个踩坑（都已修，别再犯）
1. 🔴 **ffmpeg rubberband 的 `pitch` 是频率比，不是半音**。填 2.85 以为是半音，
   实际升了 17 个半音 → 声音变花栗鼠（hf_ratio 0.007→0.089，centroid 2005→2668）。
2. 🔴 **变调结果必须读回 `buf`**。第一版把 `t3` 指向新文件就完了，但后面停顿清洗
   用的是 `buf`，变调被整体丢掉（日志显示变调成功，成品 F0 仍是 171.7 没变）。
3. 🔴 **F0 口径必须统一**：`DEFAULT_F0`(197.7) 是**前 60s** 口径，函数若取整篇会测得
   185.1（全篇比开头高约 13Hz），算出来只变调 1.14 半音（应该 2.5）。
   `f0_median()` 已强制 win=60s。
4. 🔴 **必须在 atempo 之后就地测 F0**：atempo 改了时间轴，「前 60s」覆盖的文本变了。
   按 raw 算 → 成品 191.6 vs EL 198.3，少补 3.4%。

### 🔴 顺带坐实：`--el` 逐窗对齐跨引擎不可用
x8197 走 `--el` 逐窗对齐后是 **8.94 字/秒**，而同篇 EL 是 **8.37** —— 快 6.8%。
`--el` 对的是「音节核/秒」，**跨引擎量纲差不抵消**（老记忆里说「同引擎互相抵消」只在
同引擎成立）。**一律用 `--target-cps`**（字/秒）。改用后 x8197 = 534.8s ≈ EL 536.4s ✅
