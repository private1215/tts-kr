## 三、停顿怪音根因（铁证链，不是猜测）

1. **女声 v2**：停顿处理模板取「RMS 最低的停顿段」，但全篇 **0 个合格 room tone 候选** → 模板本身带谐波隆隆声，等于把噪声当底噪铺进每一处停顿。
2. **男声 v4**：日志显示「插入 0 处」= **根本没做停顿处理**，VoxCPM2 原始输出 64 处停顿中 60 处脏，其中 13 处是 40-70dB 语音电平的**人声碎片**。
3. **填充词是 EL 同款自然特征，不能清**：80-400Hz 归一化自相关峰 h=0.5-0.93、50-160ms、-16~-29dB 的谐波孤立短段，EL 标杆自身有 52-83 处（= 韩语嗯/啊/네 自然语气填充词）；我们 42/96，密度同量级、电平时长统计无差异。**曾写了 scrub_stray 清除器，拿 EL 同口径一测 EL 自己也被杀 62/105 处 → 立即叫停。**
4. **开头伪影**：只清文件开头 1.5s 内的孤立响段（生成开头伪影，EL 无此特征），已精准清除。

### 验收口径修正（重要，曾据此误判）
停顿「脏不脏」**必须只看中段**（边缘各砍 `max(30ms, 25%)`）。否则 10ms 窗会跨到语音起音沿，产生 8-30dB 的**伪凸起**——v3 初版报 27/59 处脏，修正后女声 0 处。

### 修复链 v3/v5
合成 clean room tone（白噪声 → FFT 整形：LF<120Hz 余弦衰减除 50Hz 电源嗡、HF>5k 缓降到 0.35 → 按每处停顿自身中段 RMS 匹配电平 → 长度不变、5ms 交叉淡化），替换 ≥0.08s 停顿内容。
- 女声 `X2f_v3f`：中段脏 0（EL 女 1）
- 男声 `X1m_v5f`：中段脏 21（**全为起音缓坡测量伪影**，EL 男 66）

**男声残留定性：剩余「脏」是测量伪影，剩余听感来自填充词/短词（EL 同款），不修。**

## 四、号码段根因与修复（第八轮核心）

- **ASR 定位纪律**：`faster-whisper-small`（`Systran/faster-whisper-small`，cpu/int8）**只能用分段时间戳**。词级时间戳与分段时间戳不一致、不可用于定位——曾据此误判号码在 236s，后经 v2/v3f 同位置对比证伪（两者号码段电平差 ≤0.1dB），用分段时间戳重定位到 212.38-218.46s。
- 定位结果：我们数字区 214.11-215.80（1.69s，**154ms/位**）vs EL 212.63-214.63（2.00s，**182ms/位**）。我们快 15%，后半段间隔挤到 0.13-0.15s（EL 均匀 0.23-0.27s）。
- 佐证：EL 的 ASR 识别带连字符 `010-6721-4432`，我们是一整串 `010671443` → 缺少组间停顿。
- 修复：新增 `deploy/number_fix.py`，对数字区做 atempo 1.18× 拉伸 + 10ms 交叉淡化嵌回。调用 `number_fix.py X2f_v3f.wav X2f_v4.wav 214.05 215.85 1.18` → 1.80s→2.11s，位速 181ms ≈ EL 182ms，全长 518.78→519.07s。

## 八、⚠️ 5s 细窗速率比对不可信（已证伪，别再据此调 atempo）

想把「逐 60s 窗 atempo」细化到 5s 以自动发现局部节奏异常（`rate_profile.py`）。
结果 82% 窗落在 ±15% 内、中位偏差 9%，但报出 105s 偏慢 60%、180s 偏慢 48% 等离群点。

**拿 ASR 一比对，全是假象**：100-112s 我们在读「타러 갈지…두드려 맞을지」，
EL 已经读到「두드려 맞을지…」——两边存在 **1~3 秒的文本漂移**，
同一时间点说的不是同一句。两边字符/秒实测 5.58 vs 5.58、5.25 vs 5.25，几乎一致。

🔴 **纪律：细粒度（≤5s）速率比对必须先用 ASR 做文本对齐，
时间比例插值在存在秒级漂移时完全不可用。**
结论：**不存在系统性语速问题，不要再动 atempo。**

## 十、🔴 生产默认 ≠ 最佳链路（员工已踩到）

原因：我们盲听验证出来的最佳链路是

EMOTION_PRESETS 里 standard→qwen）。**员工天天用的根本不是我们验证过的东西。**

显存现实（engine_select.py 头部铁律：显存串行，绝不并行）：
- nvidia-smi idx0 = RTX3060 12G（CUDA device 1）= 生产卡，现用 4.24G，剩 ~8G
