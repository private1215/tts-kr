## 一、🔴🔴 本轮最大发现：变调吃掉了 62% 的音色

### 口径
说话人相似度 = campplus 余弦，参考 `EL_male.wav`，**同人阈值 0.75**；
所有对比**同素材同长度**（旧口径「15s 裸推理 vs 长篇成品」会掩盖最大一项）。

### 逐级消融（裸推理 447s，6cdd 文案）

| 阶段 | 相似度 | 增量 |
|---|---|---|
| EL 原声 509s（上限） | **0.9628** | |
| 裸推理 voxcpm 447s | **0.8530** | −0.110（引擎自身；第二篇 0.8482，一致） |
| 仅 mp3 编码 | 0.8525 | −0.0006 |
| 仅 LUFS 归一 | 0.8509 | −0.0015 |
| **+ 变调/变速** | **0.6739** | **−0.1770 ← 62% 的损失** |
| + 停顿清洗 | 0.6798 | +0.006 |
| + EQ | 0.6856 | +0.006 |
| 线上成品 r35 | 0.6841 | −0.002 |

### 变调 vs 变速分离 + 剂量-反应

| 处理 | 相似度 | F0 |
|---|---|---|
| 不动 | **0.8509** | 180.8（−8.3%） |
| 只变速 fs=1.12 | **0.8543（无损）** | 180.8 |
| 上搬 R=1.020 | 0.8303 | 184.0（−6.7%） |
| 上搬 R=1.050 | 0.7902 | 188.3（−4.5%） |
| **上搬 R=1.094（旧生产）** | **0.6660** | 198.3（+0.6%） |

**凶手只有 asetrate，变速完全无害。** 机理：`asetrate` 是整体重采样，把 F0
**和共振峰一起**搬 R 倍；共振峰是说话人身份载体。音高对齐了，声道形状换了个人。
**旧生产 0.666 < 同人阈值 0.75 —— campplus 认为成品和喂给引擎的 EL 参考不是同一个人。**
这就是「不像真人」的客观对应物。

已证伪的替代方案：rubberband R=1.094 → 0.5484；`formant=preserved` → **0.4436**（最差）。

### 推翻的两条旧结论
1. ❌「campplus 看不见音高（变调前后只差 0.004）」→ 错，对整体重采样极其敏感。
2. ❌「后处理逐项叠加只解释 0.0013」→ 错，那是 15s 裸推理 vs 长篇成品的**长度口径错误**。
3. 连带修正「后处理已到顶，只剩音色/引擎」。

## 二、✅ 已上线：工作点 h5（音色优先）

### 为什么不能简单「不变调」
变调顺手还修了低频：不变调时 **60~150Hz 是 EL 的 2 倍（+9.05σ）**，正是「闷」的频段；
平坦度从 −1.58σ 升到 +4σ。所以换工作点必须同时上高通。

| 版本 | Σz² | 音色 | 60~150 | 150~300 | F0 |
|---|---|---|---|---|---|
| 旧生产 r35（目标 197.7） | 10.6 | 0.6841 | +1.37σ | +0.32σ | 194.9 |
| 不变调裸 | 139.4 | 0.8696 | **+9.05σ** ✗ | −3.58σ | 171.7 |
| 不变调 + HP120 | 108.5 | 0.8550 | +1.52σ | **−7.42σ** ✗ | — |
| h5（diag 离线） | 33.0 | 0.7986 | −0.74σ | −0.05σ | 182.9 |
| **h5（服务端全链路 494.4s）** | **19.6** | **0.7700** | −0.19σ | +2.20σ | 187.2 |

🔴 **Σz² 的正确判据是「落进 EL 自身分布」（17~240，中位 59.6），不是越小越好。**
旧生产的 10.6 比 EL 自己全部样本都低 = **过拟合一把尺子**；
新线上 19.6 落在 EL 分布的下缘（即 EL 自身最好水平），且音色 +0.086。

### 改动（`app/fix_chain.py`，备份 `.bak-before-h5`）
- `DEFAULT_F0["m"]` 197.7 → **188.0**（两处定义）
- `EQ_MALE_BOOSTS` / `EQ_MALE_TMPL` 前置 `highpass=f=110:poles=2`
- `MALE_250` −0.45 → **+0.75**（TMPL 里 −0.75 → +0.45）

已 `daemon-reload` + `restart`，root=200；男女声冒烟均通过（男 71.6s / 女 80.3s，各 1 块）。
**服务端全链路长篇复验（494.4s，6cdd 文案）：Σz² 19.6 / 音色 0.7700 / F0 187.2。**
