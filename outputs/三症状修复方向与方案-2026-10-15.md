## 第一部分：三症状的量化定位（今天新做的测量）

### 1. 先排掉三个假线索

| 假设 | 结论 | 证据 |
|---|---|---|
| 缺某个频段（频谱能量分布不对） | ❌ **不成立** | 我们 mp3 vs EL mp3 各频段占比全部在 **±13%** 内（b60_150 −13.3% … b4k_8k +13.5%） |
| mp3 编码把高频压没了 | ❌ **不成立** | EL 过 mp3：b4k_8k 1.3083→1.3089（**−0.0%**）；裸模型过 mp3：0.03446→0.03449（−0.1%） |
| 重采样器质量不行（换 soxr） | ❌ **不成立** | 换 `aresample=resampler=soxr:precision=28`，数值与默认**完全一样** |

🔴 顺带纠正一条旧口径：`t_cur.wav` 是 553.6s 的**旧版**，不是当前 496s 生产版。
之前「我们 wav 0.03496 vs mp3 0.02225，mp3 掉 36%」是**拿旧版 wav 比新版 mp3**，无效对比。

### 2. 真凶：同一段语音被时域拉伸算法「揉了两遍」

`fix_chain` 一直在做**两次 WSOLA**：

```
① 变速：每窗 atempo = 1/fs        （语速锚 8.37 字/秒 → fs ≈ 1.086，即放慢 8.6%）
② 变调：asetrate=sr*R, aresample, atempo = 1/R   （F0 216 → 197.7，R = 0.914）
```

**而变调 R=0.914 本身就把时长拉长 1/0.914 = 1.094×** —— 语速锚只要 1.086×。
→ 先放慢 8.6%，再拉快 9.4%，**两步几乎完全抵消，等于把语音白揉两遍**。

WSOLA 反复揉捏的听感就是**起音被抹、辅音糊掉、过渡发硬** ——
与「吃字 / 卡字 / 电子音」三个症状**完全对应**。

### 3. 隔离实验（24k，拿 EL 真人素材当前后一致的对照）

| 处理方式 | 平坦度 | 相对 EL 保持率 |
|---|---|---|
| EL 原样 | 0.04928 | 100% |
| 只 atempo=0.988 | 0.04857 | **98.6%**（温和拉伸几乎无损） |
| 只重采样（变调） | 0.04361 | 88.5% |
| **A 现役：两次 atempo** | 0.04133 | **83.9%** |
| **B 融合：一次 atempo** | 0.04355 | **88.4%** |

### 4. 修复后的实测（494s 同一文案，同口径 probe_g）

| 指标 | 上一版（揉两遍） | **新版（揉一遍）** | EL | 判定 |
|---|---|---|---|---|
| **Σz²** | 72.2 | **27.1** | 中位 59.6 | ✅ **已进入 EL 分布** |
| **平坦度**（前60s） | 0.0242（**−7.22σ**） | **0.0373（−2.89σ）** | 0.0461 | ✅ 大幅收敛 |
| 150~300Hz | +1.80σ | **−0.41σ** | — | ✅ 回到分布内 |
| 4k~8k | +2.98σ | +3.13σ | — | ⚪ 未变（旧有问题） |
| 发声占比 | +2.35σ | +2.83σ | — | ⚪ 略升 |
| 时长 / 字每秒 | 496.43s / 8.34 | **494.87s / 8.37** | 509.0s / 8.14 | ✅ 锚点达成 |

🔴 **口径校正**：probe_g 只测前 60s，而我们的前 60s 恰是**最坏样本**、EL 的**最好样本**
（我们 0.0358 < 全篇 0.0387；EL 0.0493 > 全篇 0.0433）。
按**全篇**口径：我们 **0.03867** vs EL **0.04329**，只差 **1.12 倍** ——
电子音的客观缺口比 −2.89σ 看起来小得多。

## 第二部分：结合五六天记录，修复方向与优先级

### 已排除（复用 10-10~10-15 的 25 条 + 今天新增 3 条）

- **架构类**：分块背锅（1块 vs 2块互相似 0.9947）、GS 零样本、换参考切片（±0.0007）、后处理逐项（合计只解释 0.0013）
- **频谱类**：静态 9 标量 / HNR / 质心 / F1F2 全在 EL 分布内；+262Hz 补频 EQ（耳朵两位置相反）；女声增量 EQ（加重闷感）
- **韵律类**：情绪平淡（2/2 选"有起伏"）、断句停顿（第24轮 0 票）、字间清晰度（1:1）、语速（8.37 = EL 8.37）
- **底噪类**：roomtone 假设（受控实验只差 1.8dB）、底噪斜率（两性别全翻车）
- **卡顿类**：填"严格为 0 的样本"、填"整帧绝对零"、慢调制做起伏、σ 当目标（被 54 个数字零帧污染）
- 🆕 **编码类**：mp3 压高频（EL 自己 −0.0%）
- 🆕 **器件类**：换 soxr 重采样器（数值一模一样）
- 🆕 **频段类**：缺某个频段（各频段 ±13% 内）

### 方向与方案（按性价比排序）

|---|---|---|---|---|

## 第五部分：追加的客观优化（不依赖员工反馈，本轮后半程完成）

### ① 变调窗 60s → 15s（跨文案验证后定案）
融合后复查**跨窗一致性**，发现 F0 跨窗极差反而变差（r31 21.2%）。
逐窗看是两个离群窗（174.7 / 217.6 Hz）—— 变调按 60s 校正，漂移发生在**窗内**。
新增 `--pitch-win`（只细化变调窗，速度窗保持 60s 避免引入语速抖动）。

跨文案验证（同一条裸输出，各跑 pw=60 / pw=15）：
| 文案 | pw=60 | pw=15 | EL 参照 |
|---|---|---|---|
| 6cdd | 12.5% | **10.2%** | 15.1% |
| d172 | 11.9% | **8.2%** | 15.1% |
两篇一致改善 → 默认定为 15s。⚠️ 现在比 EL 更平（8~10% vs 15%），若员工说「太单调」就往回调。

### ② 全篇近 300 处停顿填的是**同一段噪声**
`pause_clean_v3.synth_tone(..., seed=42)` 默认种子是常量，两处调用都没传 seed，
且内部取固定偏移 → 长度相近的停顿拿到**同一段波形**；长篇实测有 288~290 处停顿被清洗。
重复出现的相同噪声正是耳朵最容易察觉的合成感。改为按停顿起始时间派生种子。
验证：不同种子互相关 −0.0076、同种子 1.0、**RMS 完全一致**（只换实现，不动电平/频谱）。

### ③ 自适应高频从「一次反算」改成「迭代收敛」
`highshelf` 不是理想砖墙，一次反算到不了位：实测 b4k_8k 残差 +0.31 dB，
而这一项占 Σz² 的 36%。改成量→补→再量，最多 3 轮、残差 <0.25dB 即停。

### 🔴 ④ 试过并回退：250Hz 也做成自适应（**最贵的一条教训**）
同配置连跑两次证明平坦度是**配置**导致的，不是生成波动：

| | r33 | r34 | 判定 |
|---|---|---|---|
| 平坦度 | 0.0309（−5.02σ） | 0.0323（−4.55σ） | 差 4.5% → 配置决定 |
| 发声占比 | 0.5553（−0.10σ） | 0.5743（+2.79σ） | 差 2.9σ → 生成随机量 |

**机理**：`平坦度 = 几何均值/算术均值`，而**窄带衰减对几何均值是致命的**——
几何均值对接近零的频点极敏感，陷波一深分子就塌，算术均值却几乎不动。
`equalizer=f=250:t=q:w=1.1` 正是窄带。历史同源教训：`highshelf -9.5dB` 把 flat 打到 −6σ（发假）、
`MALE_250 -1.5dB` 过冲使 Σz² 反升到 44.9。
→ 🔴 **以后用窄带 EQ 追某个频段的 z 分时，必须同时盯住平坦度。**

### 已证伪、不再追的一条
**「发声占比」是模型属性，后处理改不动。** 抬停顿底噪（对齐 EL 的 −62.2 dB）完全无效
（Σz² 23.9→23.8）—— 因为 `voiced = 帧RMS > p30×2.2 的比例`是相对阈值，整体抬高时 p30 跟着走。
真因是这篇成品比 EL 同文案快 2.8%（494.6s vs 509.0s），停顿时间本来就少，属正常样本差异。
