# 五六天全景复盘 + 质变方案

> 时间跨度：2026-10-10 ~ 10-15，共 **23 轮员工反馈（a~w，即第8~30轮）**
> 本文回答两个问题：**这五六天到底攒下了什么**，以及 **还能不能有质的提升**。

## 第一部分：这五六天攒下了什么

| 日期 | 主线 |

| 10-10 | 句尾下降/呼吸的实验多 seed 翻车 → 关闭；`scrub_stray` 误杀韩语语气词叫停 |

### 2. 被证伪 / 排除的假设（**这是最有价值的资产：25 条**）

| 类别 | 已排除 |
|---|---|
| **架构类** | 分块背锅（1块 vs 2块互相似 0.9947）、GS 零样本、换参考切片（±0.0007）、后处理逐项（合计 0.0013） |
| **编码类** | MP3 是电音杀手（EL 同规格 128k）、16k 采样「发假」（EL 实际带宽就是 8k） |
| **频谱类** | 静态 9 标量、HNR、频谱质心、F1/F2 全部落在 EL 分布内；+262Hz 补频 EQ（耳朵两位置相反）；女声增量 EQ（加重闷感）；HF 过量是 asetrate 造成（裸推理就 +15.4σ） |
| **韵律类** | 情绪平淡（2/2 选"有起伏"）、断句停顿（第24轮 0 票）、字间清晰度（1:1）、语速（8.36 vs 8.37） |
| **底噪类** | roomtone 假设（受控实验只差 1.8dB）、底噪斜率（端到端两性别全翻车） |
| **方法类** | 共振峰测量不可重复、5s 细窗速率比对（1~3 秒文本漂移）、whisper-small 判韩语数字 |
| **卡顿类** | 填"严格为 0 的样本"、填"整帧绝对零"、慢调制做起伏、σ 当目标（被 54 个数字零帧污染） |

🔴 **一句话总结：凡是"能用静态指标测出来的维度"，基本全被排除光了。**

### 3. 反复出现、至今没解决的症状

| 症状 | 出现轮次 | 现状 |
|---|---|---|
| **「闷 / 像感冒后发出的声音」** | f/g/i/j/m/n/p，**디아 连续 6 轮一字不差** | ❌ 未解决。已从频谱轴撤到「时域组织 + 整体质感」 |
| **「卡顿 / 吃字 / 瞬间卡顿」** | 第2轮、10-12、10-13、t/u/v/w | 🟡 部分解决：硬切/真零已清零，σ 仍偏低 |
| **「电子合成感 / 电音严重」** | p/q/r/s/t/w，**连续 3 轮全票是最稳定信号** | ❌ 未解决 |
| **「不如 EL，不能直接发客户」** | **连续 4 轮 15 张票全选 EL** | ❌ 未解决 |

| 「开头有点别扭」 | e | ❌ VoxCPM2 自带韵律，后处理改不了 |

### 4. 指标口径踩过的坑（**血的教训，价值不亚于结论本身**）

- `probe_g` 曾硬编码只测前 60s → 同一成品换切片 Σz² 差 **4 倍**（211~877）
- σ 被离群值撑大 **9.6~26.8 倍** → 「−3.08σ 已达标」实为 **−26.7σ 假达标**
- 字数与时长取自不同来源 → 误判「语速偏慢 51%」，正确值是 8.36
- 8197 是异常样本（11.5 字/秒，超 EL 37%），基于它的结论全作废
- 女声只生成前 1500 字 → 算出「快 2.6 倍」的假结论
- flat 采样率口径、必须传幅度谱、F0 的 fmax 设错会检成 2 倍频
- 短片 4k~8k 系统性低 40~60% → 拿短片调高频会得到**相反**结论
- 同配置连跑 7 次 Σz² 波动 **4 倍** → 收益 <10% 全淹没在噪声里

### 5. 操作铁律（踩一次记一条）

- systemd drop-in 改完必须 `daemon-reload` 再 `restart`
- 临时文件不能放 `/tmp`（EXDEV）
- `volume=%gdB` 不是 `%gdBB`（多一个 B = +18dB）
- 判活用根路径 200，**必须真跑一条生成**
- 服务器时区 UTC；`sudo cat /proc/.../environ` 不能用重定向
- 🔴🔴 **永远不要整目录 rsync**（本地是旧快照，服务器才是最新的）
- `vox-tts:8400` 只有 `["male"]`、`omni-tts:8300` 只有 `["female"]`

## 第二部分：还能不能有质的提升？

### 🔴 先说结论：**能，但不在"继续调后处理"上。**

### 判断依据 1：后处理这条路已经到顶

**老男声 voxcpm（10-15 03:45 生成）的实测**：

| 维度 | 我们 | EL 男标杆 | 结论 |
|---|---|---|---|
| Σz²（9 频段 + flat + 发声占比） | **21.2** | EL 自己中位 **59.6** | ✅ **比 EL 的中位还好** |
| 150~300Hz | 0.2559 | 0.2541 | 几乎完美 |
| 语速 | 8.36 字/秒 | 8.37 | 一致 |
| 停顿电平中位 | −56.55 dB | −56.60 dB | 一致 |
| HNR / 质心 / F1 / F2 | 全部落进 EL 分布 | — | 一致 |

👉 **能测的维度全部对齐了，员工照样说「闷」「电子合成」「不像真人」。**

这说明：**剩下的差距根本不在我们一直在测、一直在改的那些维度上。**

### 判断依据 2：真正没解决的只有一件事 —— **音色本身**

| | 音色相似度（campplus） |
|---|---|
| **裸推理**（用现役 EL_male 参考） | **0.9539** |
| **线上成品** | **0.8444** |
| 差额 | **0.11** |
| 后处理逐项叠加能解释的 | **0.0013** |

🔴 **引擎本来就能产出 0.95 的音色，但我们线上只有 0.84。
有 0.11 在生产链里被吃掉了，凶手至今没抓到。**

这个实验在 **10-13 就已经铺好**（嫌疑名单：PROSO / PBA / roomtone / breath /
peakfit / envshape / transient），**但整整两天过去，从没真正跑过**。

### 判断依据 3：今天刚证明，「引擎 + 原生音色」才是大头

今天我把性别判定改坏了一次（男声被判成女声），结果：

| | Σz² | 4k~8k |
|---|---|---|
| 改坏前 | 21.2 ✅ | 0.0145 |
| 改坏后 | **3519.6** 🔴 | **0.0460（EL 的 3.6 倍）** |

员工原话：**「尖锐，像老播放器加快速度播放，根本不是人能发出来的声音」**。

👉 一次配置错误就能把指标打烂 166 倍、让员工给出"不是人声"的评价
→ **反过来说，决定成败的是「引擎 + 它原生出来的音色」这个大开关，
不是 EQ 0.5dB、底噪 3dB 这种细节。**

## 第三部分：质变的两条路径

### 路径 A（最快，1~2 天）：**抓吃音色的凶手**

**做什么**：拿裸推理那份（0.9539）当基线，把生产链的模块**逐个往上叠**，
每叠一个测一次 campplus，定位掉分的那一步。

**嫌疑名单**（10-13 已列）：`PROSO`（改 F0/时长）、`PBA`、`roomtone`、
`breath`、`peakfit`、`envshape`、`transient`。

**为什么值得先做**：
- 目标明确：把线上音色从 0.8444 拉回 **0.93+**
- 成本：几条短音频 + campplus，不用等 7 分钟长篇
- 它是**唯一一个「机器指标和员工听感都对得上」的抓手**
  （0.95 vs 0.84 这个差距是真能被听出来的）
- 而且它 10-13 就铺好了，属于**欠账**，不是新开坑

### 路径 B（最大，3~5 天）：**用 36 条 EL 案例微调引擎**

**做什么**：案例库 **36 条全是 EL 生成**，而且**只有 2 个说话人**
（yohan 男 13 条 / SOLA 女 22 条）—— 这是一份**天然的 SFT 数据集**。
用它微调 GS / CosyVoice3，让引擎**原生**产出 EL 音色，
而不是靠后处理去逼近。

**为什么这是"质变"**：
- 现在我们做的是「用一个别的音色，后处理磨成接近 EL」→ 天花板明显
- 微调是「让引擎直接就是那个音色」→ 音色、韵律、质感一起到位
- 🔴 **这条路径其实从没真正试过**：
  - 之前下架的是「GS **零样本**」（0.802/0.812），**不是微调版**
  - GS 自动微调的 cron `0 19 * * *` 服务器是 **UTC**（= 北京凌晨 3 点），
    而且装完时当天 19:00 已过 → **从来没跑过**，exp 权重目录一直是空的

**建议**：先把 cron 时区修正 + 手动跑一次微调，出一版微调模型，
用同一条 4143 字长篇跟现生产做 A/B，让员工选。

### 路径 C（配套，立刻改）：**改掉提问方式 + 加一条上线回归闸门**

**① 多做"二选一裁决题"，少做"哪里不像"定位题**

| 题型 | 表现 |
|---|---|
| 定位题（"最不像真人的地方"） | **发散**：断句 2/3 → 下轮 0 票；电子感 2/2 → 后来 1:1 |
| 裁决题（"这两个方案哪个更像 EL"） | **稳定**：第 26 轮 OmniVoice 3/3 全员一致，是唯一一次做出重大决策的依据 |

→ 6 天里只有 1 次用了裁决题，而它是唯一拿到全员一致的题型。

**② 上线前必须跑「回归对照」**（今天就是栽在这）

新铁律：**每次改链路/配置后，重跑一条长篇 + `probe_g`，Σz² 不许比上一版差**。
今天如果做了这一步，Σz² 21.2 → 3519.6 会**当场**被发现，
根本不会让员工听到"不是人能发出来的声音"。

## 第四部分：一句话

> **六天里我们把「能用指标测出来的东西」全部对齐了，
> 员工还是说不像 —— 这说明剩下的差距在指标之外。
> 而唯一的、机器和耳朵都对得上的指标是音色相似度：
> 引擎能给 0.95，我们线上只有 0.84。
> 先把这 0.11 抓回来（路径 A），再用 36 条 EL 案例微调让引擎原生就是那个音色（路径 B）。
> 继续在 EQ / 底噪 / 停顿这些细节上磨，不会带来质变。**
